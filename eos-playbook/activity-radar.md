# EOS Activity Radar

The Activity Radar describes how the ecosystem function engages and what expertise can contribute. Operating postures describe how someone engages. Functional roles describe the work people do.

## Choose how to engage

| Operating posture | When it fits |
| --- | --- |
| Architect | The work needs a structure, decision rights, standards or a way to exchange value. |
| Steward | A relationship, shared resource or way of working needs care over time. |
| Orchestrator | Independent parties need to coordinate contributions and handoffs. |
| Advocate | An audience needs someone to represent its needs and get feedback to an owner. |
| Network maker | A durable relationship could create several routes to future work. |
| Matchmaker | A particular person or team needs a specific collaborator or resource. |
| Translator | People need to understand each other’s goals, constraints or technical work. |

## Functional roles

See the [service catalogue](capabilities.md) for the work these roles can contribute to.

| Functional role | Activity to own or support |
| --- | --- |
| Ecosystem Strategy | Set direction and allocate resources against shared outcomes. |
| Partnerships & Business Development | Agree what partners will do together and what each gets. |
| Developer Relations / Technical Evangelism | Help developers build and take recurring problems to product or engineering. |
| Developer Education & Content | Create tutorials and training around practical tasks. |
| Community Engagement | Help participants find work, relationships and support. |
| Grants & Acceleration | Set funding criteria and help applicants meet milestones. |
| Tokenomics & Incentives | Assess how rewards and costs affect participation and liquidity. |
| Regulatory & Compliance | Identify regulatory dependencies, approvals and specialist input. |
| Core Protocol Engineer | Lead changes to shared technical infrastructure and assess constraints. |
| Smart Contract & dApp Dev | Build applications and surface integration or tooling problems. |
| Product Management | Own roadmap choices and decisions on product feedback. |
| Product Marketing | Turn product changes into positioning and practical launch guidance. |
| Marketing & Growth | Choose audiences, channels and experiments to test distribution. |
| Content Creator / Storytelling | Explain how technology works and what people have done with it. |
| Events & Hackathons | Design gatherings around practical work and follow-up. |
| Ecosystem Research | Track changes and turn evidence into hypotheses or decisions. |
| Venture & Fundraising | Help teams meet suitable investors and prepare for funding decisions. |
| Ecosystem Program Manager | Coordinate milestones, resources and handoffs across teams. |
| Security & Audit Lead | Coordinate assurance and responses that involve multiple teams. |
| UX / Product Designer | Find where people get stuck and test a better route. |
| Governance Coordinator | Organise proposals, feedback and traceable decisions. |
| Infrastructure / DevOps Engineer | Maintain shared environments and make their health visible. |
| Entrepreneurs-in-Residence | Help a new venture reach a first useful product. |
| Ecosystem Social Insights | Bring recurring concerns and emerging narratives to teams that can respond. |
